# ⚡ SILTUS — Baldosa Piezoeléctrica (Green Power Hack)

> **Equipo:** Cristian Guerrero, Gustavo Mejía, Carlos Lema, Daniel Vaca, Juan Rivera

---

## 📌 Descripción del Proyecto
**SILTUS** es una solución tecnológica enfocada en la sostenibilidad urbana. El proyecto consiste en el desarrollo de una baldosa piezoeléctrica capaz de convertir la presión mecánica producida por el paso peatonal en zonas de alto tránsito (estaciones, centros comerciales, universidades) en energía eléctrica limpia.

La energía generada se destina a alimentar dispositivos de bajo consumo (sensores IoT, luces LED) o se almacena en baterías/condensadores para sistemas de respaldo.

---

## 🛠️ Especificaciones Técnicas y Materiales
* **Capa Superior:** Acrílico de alta resistencia (20 mm) para protección contra humedad y desgaste mecánico.
* **Capa Piezoeléctrica:** Matriz de sensores de cristales piezoeléctricos (discos de 20 mm).
* **Base Estructural:** Estructura ligera y duradera de PVC o madera reciclada ($30 \times 30\text{ cm}$).
* **Sistema de Almacenamiento:** Conexión hacia baterías/condensadores para acumulación o uso inmediato.
